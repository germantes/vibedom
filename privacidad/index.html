Privacidad

Qué datos usa vibedom

vibedom no tiene cuentas, ni cookies de seguimiento, ni analítica de terceros. La música se sintetiza en tu navegador. Esta página explica lo poco que sí viaja por la red.

Última actualización: 1 de noviembre de 2026.

Lo esencial

  • No hay registro, cookies propias, píxeles ni analítica de vibedom.
  • No guardamos el HTML, las capturas ni el contenido de las webs analizadas.
  • La música se genera en tu navegador; no hay audio pregrabado ni streaming.
  • Los enlaces compartidos llevan la semilla dentro: no necesitan servidor ni base de datos.

Qué ocurre cuando analizas una URL

Al pulsar «Escuchar mi web», tu navegador envía la URL que escribes a nuestro backend en Render (Frankfurt). El backend descarga la página pública, extrae señales de diseño y envía esas señales a Google (Gemini o Vertex AI) para que genere la Semilla Sonora.

  • La URL y el HTML se usan para ese análisis. No se guardan en una base de datos ni se venden ni se usan para publicidad.
  • La semilla resultante se guarda en memoria hasta 6 horas para no repetir el análisis si alguien vuelve a escanear la misma URL. Al reiniciar el proceso, desaparece.
  • La traza técnica guarda el host, el estado HTTP, el tamaño y los tiempos de cada paso (por ejemplo, «css 349 KB, 200 ms»), nunca la ruta completa ni el contenido.
  • Render y Google pueden conservar registros técnicos de las peticiones según sus propias políticas. No controlamos esos registros.

Si no quieres enviar una URL, puedes escuchar los presets de la demo o generar una semilla local sin pasar por la IA.

Qué ocurre con el widget

El widget embebible no llama a la API de vibedom ni a la IA. La semilla viaja dentro del data-seed del propio snippet, así que cada visitante escucha la variación sin que se envíe la URL de la página anfitriona.

  • No usa cookies ni localStorage.
  • El primer clic descarga Tone.js desde jsDelivr, que ve la IP del visitante como cualquier CDN.
  • El audio se sintetiza en el navegador; no se descarga música ni se sube nada.

Servicios externos

  • Render: aloja el backend que analiza las URLs y sirve las vistas previas de los enlaces compartidos.
  • GitHub Pages: sirve la web estática de vibedom.dev.
  • Google: Gemini o Vertex AI generan la semilla; Google Cloud factura el consumo del proyecto.
  • jsDelivr: entrega Tone.js al pulsar play en la demo o en el widget.

No usamos redes publicitarias, ni Google Analytics, ni cookies de marketing. Tampoco creamos perfiles de visitantes.

Tus derechos y contacto

Como no hay cuentas ni una base de datos de usuarios, no hay un perfil que borrar. Si tienes dudas sobre este tratamiento o quieres ejercer tus derechos de acceso, rectificación o supresión, escribe a gtorrestendero@gmail.com.

Si cambia lo que hace vibedom, actualizaremos esta página y la fecha de arriba. El código del proyecto es abierto y puedes revisar el tratamiento en GitHub.
